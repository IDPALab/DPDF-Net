# DPDF-Net

Official implementation of DPDF-Net for wetland hyperspectral image classification.

## Reproducibility Demo

The `main` branch contains selected source files for browsing. Due to file size limits on direct repository uploads, the complete project is distributed as a ZIP archive through GitHub Releases. The archive includes the full source code, dependency file, and data files needed to run the MongCai and CamPha demos.

[Download the complete DPDF-Net reproducibility package (v1.0.0, ZIP)](https://github.com/IDPALab/DPDF-Net/releases/download/v1.0.0/DPDF-Net.zip)
